# AnimeList

AnimeList è un progetto che permette di gestire e visualizzare una lista di anime in modo semplice e intuitivo.

## Funzionalità

- Visualizzazione lista anime
- Ricerca di anime
- Visualizzazione dettagli anime

## Tecnologie utilizzate

- HTML
- CSS
- JavaScript
